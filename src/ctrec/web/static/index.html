대기 중 0초 모델 -

이 서비스는 무엇을 하나요?

입력한 환자 정보를 공개된 임상시험의 선정·제외 기준과 비교해, 검토해 볼 만한 임상시험과 그 근거를 정리합니다. 임상시험 참여 자격을 확정하지 않습니다. 실제 참여 가능 여부는 연구기관의 스크리닝과 연구자 판단으로 정해집니다.

  1. 환자 정보 입력 — 진단, 치료 이력, 검사 결과 등을 자유롭게 적습니다.
  2. 분석 — AI가 정보를 정리하고 임상시험 기준과 비교합니다. 단계마다 진행 상황이 표시됩니다.
  3. 추가 질문 — 판단에 필요한 정보가 부족하면 질문이 나옵니다. 모르는 항목은 "모름"으로 답할 수 있습니다.
  4. 결과 확인 — 시험별 매칭 상태와, 충족·불충족·정보 부족·추가 확인이 필요한 조건을 근거와 함께 봅니다.
