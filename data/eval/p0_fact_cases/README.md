# P0-1·P0-2 독립 평가 사례 (정답 쪽)

작성: 서연 (데이터) · 2026-11-08 · 기준선 측정 `integration/dcvc` `4f81460`

> 데이터 작성 / 임상 검수 미완료. 합성 문장이며 실제 기록의 빈도·분포를 대표하지 않습니다. 결과는 건수이며 정확도가 아닙니다.

## 1. 작성 원칙과 독립성

- 기대값은 원문 문장의 처리 원칙으로만 정했습니다. 엔진·모델의 출력을 보고 정하거나 고치지 않았습니다.
- 판정 구현 코드(`ctrec.value_grounding`, `ctrec.evidence_directness` 등)는 열어 보지 않았습니다.
- 완전히 비공개로 작성한 것은 아닙니다.
  - 평가 스크립트의 입력 형식(`scripts/eval_m_holdout.py`)과 held-out 6 사례 문장은 읽었습니다.
  - 1차 사례(48건)의 현재 결과는 확장 전에 보았습니다. 확장 사례는 결과를 보고 고치지 않았습니다.
- 기대 처리
  - `accept`: 그 값을 사실로 채택
  - `hold`: 채택하지 않고 보류
  - `conflict`: 상충으로 탐지. 보류도 안전 처리로 셉니다.

| 원칙 | 기대 |
|---|---|
| 같은 항목·같은 시점에 다른 값 | hold |
| 시점이 다른 값 중 이후 값으로 대체된 과거 값 | hold |
| 시점이 다른 값 중 가장 최근 날짜 값 | accept (정상 대조) |
| 부정 뒤 번복 / 문서와 자가보고 충돌 | conflict (값 사례는 hold) |
| 의료진 전언(불확실) / 가족 전언 / 기억 불확실 / 다른 사람 값 | hold |
| 확실한 본인 값(자기 보고 허용 항목) / 날짜 있는 검사값 / 문서 근거 | accept (과잉 보류 측정용 정상 대조) |

슬롯은 NSCLC 축소 범위 위주입니다(나이, ECOG, 병기, 치료 이력, 검사 수치 Hb·ANC·빌리루빈·크레아티닌·CrCl·혈소판·INR).
- 값 비교 함수가 있는 항목(나이·성별·ECOG·검사)은 값 사례로 썼습니다.
- 병기·치료 이력은 서술 사례로 썼습니다.

## 3. held-out 6 실패 집합 기대값 검토

`holdout6_failure_cases.json`의 `review` 열입니다. 결과는 **타당 24 (메모 3) / 모호 1 / 기대값 오류 0**입니다.

- **모호 1건 (H6H06):** "Self-reported age 67 or 68; no ID available and DOB unknown". 나이는 자기 보고 허용 항목이라, 67·68이 기준 문턱을 가로지를 때만 보류가 맞습니다.
- **메모 3건**
  - H6C03 "No history of hepatitis" + 만성 B형 간염: 'active' 해당 여부는 임상 판단이지만 보류가 맞습니다.
  - H6C06 "뇌전이 없음" + '전이 의심' 병변: 상충보다 불확실에 가깝고, 보류로 세야 합니다.
  - H6C10 "간질성 폐질환 부인" + IPF '추정': 보류가 맞습니다.
