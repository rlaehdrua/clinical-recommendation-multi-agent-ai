# 회의 안건: 숫자 기준을 규칙 엔진 필드로 추가할지 (WP2b · WP3 · WP4)

> 2026-11-03 · 작성: 서연 · 상태: **안건 (결정 전)**
> 결정권자: **동겸, 공정현**. 판정 계층(`tools/rule_engine.py`)은 동겸 금지 목록에 있고, 파서·스키마 변경은 팀 확인 사항입니다.
> 근거 자료: `docs/dev/wp2a_parse_pilot_NCT06928389.md` §8·§10, `docs/dev/wp2b_slot_decisions.md` §7a.
> **수치는 파싱을 마친 6개 시험 기준입니다.** 출력 잘림으로 실패한 NCT05255302·NCT04892953을 다시 돌린 뒤 갱신됩니다(두 시험에 숫자 검사·용량·기간 기준이 몰려 있음).

## 1. 안건

스테로이드 용량, PD-L1 %, 기간 일수 같은 **숫자 기준**은 지금 `categorical`(엔진 밖 결정적 기준)로 분류돼 있습니다. 파서에서는 모두 `fact_llm`입니다. 이 기준들을 규칙 엔진 필드로 추가해 `rule_engine`으로 판정할지 정합니다.

## 2. 근거

| 지표 | 값 |
|---|---|
| 파서 rule 비율 (6개 시험, 규칙 160개) | **11.9%** (19개: 나이 9, ECOG 6, 성별 4. 검사값 0) |
| WP2b CSV 분리 전 rule 비율 (같은 6개 시험, 122행) | **40.2%** → 분리 후 rule_engine 8.2% + categorical 32.0% |
| WP4 부분 재평가 대상 | 11.9%. 전체 재평가 폴백 대상(fact_llm)은 81.9% |
| WP4 절감 효과 | CSV 기준 기대치의 **약 30%** (11.9 / 40.2) |
| fact_llm이 있는 시험 | 6 / 6 (시험당 최소 6개) → 나이·ECOG 외의 사실이 바뀌면 사실상 전체 재평가 |

**대상 후보: 숫자 `categorical` 슬롯 (CSV 17행, 8개 시험)**

| 슬롯 | 단위 | 행 | 시험 | 6개 시험에 포함 |
|---|---|---|---|---|
| `med.systemic_steroid_dose` | mg prednisone eq/day | 3 | NCT04892953, NCT05255302, NCT06216301 | 1 |
| `proc.days_since_major_surgery` | 일 | 3 | NCT04892953, NCT06216301, NCT07416058 | 2 |
| `tx.days_since_last_anticancer` | 일 | 2 | NCT04892953, NCT07416058 | 1 |
| `bm.pdl1_tps` | % | 2 | NCT07098338, NCT07416058 | 2 |
| `lab.ast_alt_uln` | ×ULN | 2 | NCT04892953, NCT05255302 | 0 |
| `lab.bilirubin_uln` | ×ULN | 2 | NCT04892953, NCT05255302 | 0 |
| `lab.inr_aptt_uln` | ×ULN | 1 | NCT06216301 | 1 |
| `other.body_weight` | kg | 1 | NCT04892953 | 0 |
| `other.weight_loss_3m` | % | 1 | NCT05255302 | 0 |

- 6개 시험만 보면 해당 행이 7개라, 모두 엔진으로 옮겨도 rule 비율은 **11.9% → 약 16%**(26/160)입니다. 효과가 큰 쪽은 실패한 두 시험이라, 재실행 결과를 보고 판단하는 것이 안전합니다.
- 숫자가 아닌 `categorical`(치료력·조직형·병기·약물·생식 등, 8개 시험 55행)은 이 안건의 대상이 아닙니다. 그쪽은 명제·질문 계약 경로나 생성기 범주 연결이 맡습니다.

## 3. 선택지와 영향

| 선택지 | WP3 근거 수준 | WP4 재평가 범위 | 계약 0.2 관련 |
|---|---|---|---|
| **A. 그대로 둠** (숫자 기준은 fact_llm) | 변화 없음. LLM 판정은 근거 사실의 출처·검증 상태로만 제한 | 부분 재평가 11.9% 유지. 폴백 81.9% | 없음 |
| **B. 절댓값 숫자만 추가** (`med.steroid_dose_mg`, `bm.pdl1_tps`, 경과 일수, 체중·체중 감소율) | 숫자 사실에 단위·관찰 시점이 필요. 자기 보고 숫자(예: 복용량)는 `self_report_ok`인지 `clinical_record` 필요인지 기준별로 정해야 함 | 해당 기준이 부분 재평가로 들어옴(6개 시험 +7개 안팎) | 엔진 판정을 `CriterionResult.decided_by="rule_engine"`으로 기록. **안건 1(`RuleMeta.adjudication`) 정의에 영향** — rule로 분류할 범위가 넓어짐 |
| **C. B + 상대값(×ULN) 지원** | 환자 검사 결과에 기관별 ULN 값이 있어야 함. 없으면 판정 불가(UNKNOWN) | 간기능·응고 기준이 들어옴(주로 실패한 두 시험) | B와 같음. 판정 근거에 ULN 출처가 추가로 필요(`EvidenceRef`에 담을지 별도 결정) |
| **D. 엔진 대신 명제·질문 계약 경로로 결정적 판정** | 질문 계약의 선택지 범위(예: "10 mg 초과 / 이하")로 근거 수준을 고정 | 계약 기준은 `contract_bridge` 오버라이드로 판정이 바뀌어 부분 재평가 대상이 될 수 있음 | 계약 질문 추가(`question_contract.py`), 판정 의미 변경은 midterm 담당 합의 필요 |

공통으로 바뀌는 파일 (선택지 B·C):

| 파일 | 보호 파일? | 변경 |
|---|---|---|
| `src/ctrec/tools/rule_engine.py` | 아님 (판정 계층, 동겸 금지 목록) | 필드 추가, ×ULN 비교(C) |
| `src/ctrec/agents/criteria_parser.py` | 아님 | 프롬프트의 엔진 필드 목록(`:24-29`)과 무결성 검사 |
| `src/ctrec/schemas.py` | 아님 (`RuleMeta`는 기본값 있는 필드 추가만) | 필요하면 단위 필드 |
| `src/ctrec/agents/patient_profiler.py` | **보호 파일** | 환자 프로필에 새 숫자 항목이 필요하면 수정해야 함 → **승인 필요**. 대안은 `profile_facts`/명제 사실에서 읽기 |
| `data/parsed/*` | **보호** | 기존 26개 동결 시험은 다시 파싱하지 않음. 새 필드는 NSCLC 저장소(`data/nsclc/**`)에만 적용 |

## 4. 결정할 질문

1. 숫자 기준을 엔진으로 옮길지(B/C), 계약 경로로 둘지(D), 그대로 둘지(A).
2. B·C를 고르면 자기 보고 숫자(복용량, 체중 감소율)의 근거 수준을 어떻게 정할지. WP3 설계 §3과 연결됩니다.
3. 안건 1(`RuleMeta.adjudication`)에서 rule 범위를 "엔진 판정 가능"으로 정의할지, "결정적 판정 가능"(categorical 포함)으로 정의할지.
4. 결정 시점: 실패한 두 시험(NCT05255302, NCT04892953)을 다시 돌린 뒤 수치를 갱신하고 결정할지.

## 5. 수치 갱신 예정

- 출력 잘림 수정(선정·제외 분할 파싱)은 `criteria_parser.py`에 반영돼 있고, 재실행은 대기 중입니다(중단선: 두 시험 합계 $2).
- 재실행 뒤 이 문서의 §2 표(파서 rule 비율, WP4 폴백 비율, 숫자 후보 수)를 다시 집계합니다.
