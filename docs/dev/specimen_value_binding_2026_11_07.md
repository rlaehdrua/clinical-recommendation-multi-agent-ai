## 검체 검증 계약 (`src/ctrec/specimen.py`)

수치, 단위, 시점, 주체, 유효성과 별개의 축입니다. 값은 `blood`, `urine`, `csf`, `other_fluid`, 모름 중 하나입니다. serum, plasma, whole blood는 구별하지 않습니다.

| 값의 검체 판단 순서 | 예 |
|---|---|
| 1. 검사명에 붙은 표시 | `Urine creatinine 140`, `creatinine (urine) 1.2`, `혈청 알부민 3.5` |
| 2. 수치 뒤의 같은 절 | `Creatinine 140 mg/dL (spot urine)` |
| 3. 같은 구간의 머리글 | `CSF analysis: glucose 60, WBC 5`, `Renal: Cr 1.0` |
| 4. 문맥 | 채혈·혈액 묶음 검사가 있고 다른 검체 언급이 없을 때만 혈액. 그 밖에는 모름 |

기준의 검체는 항목 이름, 그다음 기준 문장에서 그 검사명에 붙은 표시로 정합니다. 없으면 혈액입니다.

| 비교 결과 | 판정 경로 | Fact Store |
|---|---|---|
| 일치 | 근거로 사용 | `specimen` 기록 |
| 불일치 | 근거와 충돌 계산에서 제외 | `lab:urine creatinine`처럼 별도 항목. 혈청 값과 충돌하지 않음 |
| 모름, 복수 검체 검사 | 값은 남기되 확정 근거로 쓰지 않음 | `specimen="unclear"`, `to_profile()`에서 제외 |
| 모름, 혈액 전용 검사 (Hb 등) | 근거로 사용 | `specimen="unclear"` |
| 계산·영상값 (CrCl, eGFR, LVEF) | 비교하지 않음 | 같음 |

검체는 LLM의 프로필이 아니라 원문에서 코드가 읽습니다. 구조화 입력의 `specimen=None`은 확인하지 않은 값이며 그대로 씁니다. 단독 답변("1.2")의 검체는 질문이 정합니다.
