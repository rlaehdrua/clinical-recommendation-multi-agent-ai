## 3. 경로별 차단 결과

"전"은 후보에서 matcher 호출 한 줄만 뺀 변이본입니다. 변이본에서 관련 테스트 78건이 실패하므로, 아래 통과는 경계 덕분임을 확인했습니다.

| 경로 | 입력 | 전 | 후 |
|---|---|---|---|
| 기본 Session | 저장 규칙 5건 × MET·NOT_MET·해당 없음 | 15/15 확정 | **0/15** |
| ContractSession | 같은 입력 | 0/15 (이미 차단) | **0/15** |
| 두 Session 일치 | 12개 입력의 판정·상태·기준별 결과 | 불일치 12건 | **불일치 0** |
| WP6 OfflineEvaluator | 분류 기준 7건 × reviewed 연결 통과·실패 | 14/14 확정 | **0/14** |
| WP6 | 모든 LLM 기준을 통과로 답하는 판정기, NSCLC 4개 시험 | 임상 기준 확정 | 전부 `physician_review` |
| WP6, 판정기 패치 | 분류 밖 `NCT07027514:E14`를 판단 슬롯 `cm.cardiac`에 연결 | MET | UNKNOWN. **일반 슬롯 연결은 MET 유지** |

**임상의 판단 입력 계약은 없습니다.** `decided_by="clinician"`을 만드는 코드가 없고, 테스트가 이를 고정합니다. 경계에 통과 인자를 두지 않았고, 가짜 완료 상태를 만들지 않았습니다.

**부적격 유지.**
- 문서 검증된 나이 불충족은 WP6에서 `CONFIRMED_INELIGIBLE`로 유지됩니다 (NSCLC 3개 시험).
- 기본 Session에는 문서 검증 수단이 없어 불충족이 `VERIFICATION_PENDING`입니다. 이는 계약대로이고 `b2100d8`, N2와 같습니다. `eligibility`는 `INELIGIBLE`, 외부 상태는 `CRITERIA_MISMATCH`로 유지됩니다.
- 공통 기준 불충족은 OR 시험의 모든 경로를 닫습니다. 임상 기준의 LLM 불충족만으로는 경로를 닫지 않습니다.
