# 팀원 공유: 현재 상태·한계·후속 작업 (Phase 0~9)

브랜치 `feat/team-integration-phase9` 기준입니다. 이 브랜치는 다른 팀원 커밋 `4ea12d6`(origin/main)을 통합하는 중이며, 병합 커밋은 아직 만들지 않았습니다. 처음 실행 방법은 `docs/team_local_setup.md`를 보세요.

**핵심 요약**
- 합성 데이터와 테스트용 대역(Fake LLM·Fake SDK)으로 웹 전체 흐름과 안전장치를 검증했습니다.
- **실제 유료 모델 응답은 한 번도 받지 않았습니다.** 실제 모델 품질은 미검증입니다.
- 웹의 실제 AI 분석은 기본 꺼짐입니다(`CTREC_WEB_PAID_ENABLED=0`). API 키만으로는 웹이 실제 호출을 하지 않습니다.
- 팀원 커밋 4ea12d6에서 가져온 것:
  - 객관식 확인 질문
  - 에이전트 출력·규칙 엔진 문구 한국어화
  - 시험 번역 파일
  - 추천 카드 줄글 삭제
- 보류한 것 (이유는 4절):
  - 단계별 화면 전체
  - 저장된 실행 다시 보기

상태 표시:
- **오프라인 검증**: 구현했고 합성 데이터·대역으로 테스트함
- **실제 모델 미검증**: 실제 Claude 응답으로 확인하지 않음
- **운영 미검증**: 실제 배포 환경에서 확인하지 않음
- **보류**: 통합하지 않음, 후속 작업 필요

## 2. 현재 한계

- **실제 유료 모델 응답 품질 미검증:** 추출·판정·질문(객관식 선택지 포함)·추천을 실제 `claude-sonnet-5`로 돌린 적이 없습니다.
- **프롬프트 변경:** 4ea12d6에서 프롬프트가 바뀌었습니다(한국어 출력, 객관식 질문). 파일럿 계획 해시에는 프롬프트가 들어가지 않으므로, 실제 실행 승인 때 실행 커밋을 다시 기록해야 합니다.
- **임상적 적합성 확정 불가:** 결과는 공개 기준과의 비교 참고 자료입니다.
- **실제 환자 데이터 사용 금지:** 모든 사례는 합성입니다.
- **Frozen Trial Store 제한:** 시험 26개 + 데모 1개만 검증된 기준표가 있습니다. 번역 파일도 이 26개뿐입니다.
- **단일 인스턴스 제약:** 실행 상태가 메모리에 있어 서버 1개·워커 1개만 됩니다.
- **비용 상한의 기술적 한계:** 예약은 추정입니다. 응답 없는 요청은 UNKNOWN으로 남고, 같은 키를 다른 곳에서 쓴 비용은 원장에 없습니다.
- **실제 Render 배포 미실시**
- **실사용 인증 체계 부재:** 공용 비밀번호 + 브라우저별 소유권뿐입니다.
- **CLI·스크립트는 웹 안전장치 밖:** `.env`에 API 키가 있으면 `python -m ctrec run` 등은 실제 유료 호출을 합니다.
- **숫자·날짜 답변:** 서버는 형식을 강제하지 않습니다(화면이 검사). 객관식만 서버가 거절합니다.
- **구조화 출력 스키마 여유:** `PatientProfile` 합집합 14/16입니다. `QuestionSet`은 4ea12d6로 0 → 1이 됐고 한도 안입니다.

## 4. 팀원 커밋 4ea12d6 통합 결과 (Phase 9)

`origin/main`의 4ea12d6을 이 브랜치에 `git merge --no-commit`으로 합쳤습니다(병합 커밋 전, main은 그대로).
- 충돌: 5개 파일 13곳 → 모두 해결
- 자동 병합: 8개 파일

**기능별 판단**

| 팀원 기능 | 판단 | 근거 |
|---|---|---|
| 객관식 질문 (스키마 `options`·`unit`, 생성 규칙, `_normalize`, 자동 답변 형식, `tests/test_choice_questions.py`) | **유지 + 화면·서버 통합** | 판정 의미론과 무관. 현재 화면(`app.js`)에 객관식 입력을 새로 구현하고, 서버 답변 검증을 추가함 |
| 에이전트 출력 한국어화 (Matcher·프로파일러 프롬프트) | **유지** | 출력 언어만 바뀜. 근거 인용(evidence·source_quote)은 원문 그대로라 출처 확인에 영향 없음 |
| 규칙 엔진 문구 한국어화 (`_ko`, `SEX_KO`) | **유지 + 충돌 해결** | 판정(holds)은 그대로. 검사 수치 설명은 단위 환산한 값을 쓰도록 합침(4ea12d6 쪽은 환산 전 값을 표시해 판정과 어긋날 수 있었음) |
| 확정 제외 사유 성별 한국어 (`hard_filter`) | **유지** | 문구만 |
| 시험 번역 파일·`/api/ko` | **유지 + 화면 연결** | 공개 시험 정보뿐. 화면은 원문 일치 시에만 번역, 원문 함께 표시, 모든 글자는 이스케이프 |
| trace 단계 데이터 (`profile`, `screening`, 기준별 판정 `trace_match`) | **유지(서버) / SSE에서 제외** | 파이프라인 trace에는 남김. 이 화면이 쓰지 않고 환자 원문 인용·오류 원문이 들어 있어 웹 SSE로는 보내지 않음. 판정 요약(eligibility·round 등)은 보냄 |
| 결과 이벤트 `match_views` | **제외** | 이 화면은 `display.py` 표시 정보를 씀 (같은 판정 함수 기반) |
| 추천 카드 줄글(`rationale`) 삭제 | **유지** | 현재 화면에서도 "AI 요약" 줄글을 뺌. 필드는 스키마·CLI에 그대로 |
| **단계별 화면 전체 (`index.html` 재작성, 토스 디자인)** | **보류** | 외부 CDN 스크립트·글꼴, 인라인 스크립트, 인라인 style 42곳 → CSP 위반. POST에 CSRF 헤더가 없음. 상태 이벤트의 `patient_text`(환자 원문)에 의존. 그대로 쓰려면 보안 장치를 풀어야 함. 기존 화면을 유지하고 기능만 옮김 |
| **저장된 실행 다시 보기** | **비활성화** | 코드로 확인한 문제: (1) `GET /api/replays`가 모든 저장 실행을 누구에게나 나열, (2) 재생 POST에 CSRF·소유권 확인 없음, (3) 환자 원문·프로필을 SSE로 보냄, (4) 예외 메시지를 그대로 화면에 보냄, (5) 결과 저장(기본 꺼짐)에 의존. 재생 실행에는 소유자가 없어 이 브랜치의 소유권 확인 구조에서는 동작하지도 않음 |

**다시 보기를 다시 켜려면 (후속 작업)**
- 저장 시 실행 소유자(클라이언트 쿠키 해시)를 함께 저장하고, 목록·재생을 그 브라우저에만 허용
- CSRF 헤더 확인, 소유권 쿠키 발급
- 환자 원문·프로필·기준별 근거 원문을 보내지 않거나, 합성 시연 사례로만 제한
- 보존 기간(`CTREC_WEB_OUTPUT_TTL_S`)·삭제 정책 준수, 오류는 종류만
