# 팀원 공유: 현재 상태·한계·후속 작업 (Phase 0~8)

브랜치 `feat/final-integration-readiness` 기준입니다. 처음 실행 방법은 `docs/team_local_setup.md`를 보세요.

**핵심 요약**
- 합성 데이터와 테스트용 대역(Fake LLM·Fake SDK)으로 웹 전체 흐름과 안전장치를 검증했습니다.
- 실제 유료 모델 응답은 한 번도 받지 않았습니다. 따라서 **실제 모델 품질은 미검증**입니다.
- 웹의 실제 AI 분석은 기본 꺼짐입니다.
- main에는 다른 팀원의 새 커밋이 있어 아직 병합할 수 없습니다(4절).

상태 표시:
- **오프라인 검증**: 구현했고 합성 데이터·대역으로 테스트함
- **실제 모델 미검증**: 실제 Claude 응답으로 확인하지 않음
- **운영 미검증**: 실제 배포 환경(Render 등)에서 확인하지 않음
- **개선 예정**: 아직 없거나 부분 구현

## 2. 현재 한계 (반드시 알고 쓰기)

- **실제 유료 모델 응답 품질 미검증:** 추출·판정·질문·추천을 실제 `claude-sonnet-5`로 돌린 적이 없습니다. 테스트 통과는 코드 경로·안전장치 검증이지 품질 검증이 아닙니다.
- **임상적 적합성 확정 불가:** 결과는 공개 기준과의 비교 참고 자료입니다. 참여 자격은 연구기관 스크리닝과 의료진이 정합니다.
- **실제 환자 데이터 사용 금지:** 모든 사례는 합성입니다. 실제 환자 정보를 입력·저장·전송하는 승인 절차가 없습니다.
- **Frozen Trial Store 제한:**
  - 시험 26개 + 데모 1개만 검증된 기준표가 있습니다.
  - 새 시험은 컴파일·검토 절차가 필요합니다(즉석 파싱은 기본 꺼짐).
  - 시험 정보는 고정 시점 기준이라 모집 상태가 최신이 아닐 수 있습니다.
- **단일 인스턴스 제약:** 실행 상태가 메모리에 있어 서버 1개·워커 1개만 됩니다. enforce 원장도 단일 프로세스용입니다.
- **비용 상한의 기술적 한계:**
  - 예약은 추정입니다. 요청 1건만큼 넘을 수 있습니다.
  - 응답 없는 요청은 UNKNOWN으로 남습니다.
  - 같은 키를 다른 곳에서 쓰면 그 비용은 원장에 없습니다.
  - Console 지출 한도를 함께 써야 합니다.
- **실제 Render 배포 미실시:** 디스크 영속성, 인스턴스, 대시보드 비밀값은 확인하지 않았습니다.
- **실사용 인증 체계 부재:**
  - 공용 비밀번호(Basic 인증) + 브라우저별 소유권뿐입니다. 사용자 계정·권한·감사 로그가 없습니다.
  - 공용 컴퓨터에서는 같은 브라우저의 다른 사람이 진행 중 분석을 이어 볼 수 있습니다.
- **CLI·스크립트는 웹 안전장치 밖:** `.env`에 API 키가 있으면 `python -m ctrec run`이나 기준 컴파일 스크립트가 실제 유료 호출을 합니다.
- **구조화 출력 스키마 여유 적음:** `PatientProfile`의 합집합 타입이 14개로 API 한도 16개에 가깝습니다. 필드를 추가하면 회귀 테스트가 먼저 알려 줍니다.
