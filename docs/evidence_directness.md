# 근거 직접성 검증 (Phase 10-E9) - 정책 변경 기록

이 문서는 Matcher 판정 정책의 변경 기록입니다. 기존 LLM 파일럿 기준선(64d471b 이전 Matcher)과 이 변경 이후의 판정을 구분하기 위해 남깁니다.

## 1. 무엇이 바뀌었나

| 구분 | 기존 기준선 (64d471b) | 이 변경 이후 |
|---|---|---|
| LLM 확정 판정의 코드 검증 | `evidence_type`이 `inferred`/`absent`면 보류(`_enforce_evidence`), 인용이 원문에 없으면 보류(`_enforce_quote`) | 위 두 단계 + **근거 직접성 검사**(`_enforce_directness`, `evidence_directness.py`) |
| 결과 기록 | 판정·출처(`evidence_source`)·`reasoning` 머리말 | 추가: `evidence_directness`, `validation_flags`, `llm_judgment`(코드 검증 전 LLM 판정) |
| `match_trial` 인자 | `source_text`, `input_source` | 추가(선택): `qa_log`. 기본값 `None`이면 기존 호출과 같음 |

직접성 검사는 **판정을 올리지 않습니다.** 확정 판정(yes/no, 해당 없음)에서 기준이 요구하는 필요조건이 근거에 없을 때만 판정을 unknown으로 되돌립니다. 불충족·부적격으로 바꾸지 않습니다. 검사를 통과했다고 해서 '검증된 직접 근거'라는 뜻은 아닙니다. 코드가 확인할 수 있는 필요조건을 어기지 않았다는 뜻입니다.

## 2. 검사 규칙 (첫 번째로 걸린 것이 결과)

| 결과 | 조건 | 처리 |
|---|---|---|
| `unlocated` | 인용 위치를 원문 줄 단위로 확인하지 못함 | 질문 대상(unknown) |
| `question_only` | 인용이 확인 질문 문장(Q:)에만 있음. 질문 속 조건은 환자 진술이 아님 | 질문 대상 |
| `unlinked` | 근거가 짧은 답변(예/아니요 등)뿐인데 `qa_log`의 질문 ID·대상 기준·답변 연결이 없음 | 질문 대상 |
| `conflicting` | 같은 대상에 대한 원문 진술 중 '있음'과 '없음'이 함께 있음(추측 진술은 세지 않음) | 기록 확인(UNVERIFIED) |
| `hedged` | 근거 절에 추측·불확실·모름 표현이 있음. '의심·가능성'은 부정 범위 안이면 추측이 아님("의심 소견 없음", "임신 가능성 없음") | 질문 대상 |
| `indirect` | 개념군 기준인데 개념어가 없음 / 극성이 판정과 반대 / 검사 결과를 요구하는데 검사 언급이 없음 / 치료 결과(실패·진행)를 요구하는데 결과 언급이 없음 / 연결된 짧은 답변의 극성이 판정과 반대 | 질문 대상 |
| `object_mismatch` | 근거의 대상이 기준의 대상을 덮지 않음: 다른 물질(페니실린 → 조영제), 형제 대상(가돌리늄 → 요오드 조영제), 시술·치료 기준의 특정 약어(TFCC 등)가 근거에 없음, '임신 또는 수유'에 임신만 있음 | 질문 대상 |
| `time_unverified` | 기간 조건(`time_window_days` 또는 "within N days")이 있는데 근거 날짜가 [기준일-N, 기준일] 안임을 확인하지 못함 | 질문 대상 |

대상 비교에는 이름(표기)과 포함 관계만 씁니다. 포함 관계는 조영제 ⊃ 요오드·가돌리늄 조영제 하나뿐입니다.
- 부재 판정: 근거가 같은 대상이나 상위 대상의 부재를 말해야 합니다. 대상을 밝히지 않은 부재("알레르기 없음")는 모든 대상의 부재로 봅니다.
- 존재 판정: 근거가 같은 대상이나 하위 대상의 존재를 말해야 합니다.

의학적 동등성(예: 폐경 → 임신 아님, 이 기준의 'IV contrast' = 요오드 조영제)은 정의하지 않습니다.

## 3. 기존 파일럿과의 비교 가능성

- 같은 LLM 출력이라도 이 변경 이후에는 일부 확정 판정이 unknown으로 바뀔 수 있습니다. 따라서 **기존 기준선으로 얻은 파일럿 결과와 이 변경 이후의 결과를 그대로 비교하지 않습니다.**
- 실행 기록에 남는 `llm_judgment`와 `validation_flags`로 같은 실행 안에서 전후 판정을 다시 계산할 수 있습니다. 직접성 검사가 보류한 판정은 `validation_flags`에 직접성 코드만 있고, 이때의 기존 기준선 판정은 `llm_judgment`입니다.
- 실제 Claude 반복 실험은 별도 승인 항목입니다(이 변경에서는 실행하지 않음).

## 4. 보호 파일 검사

`tests/test_llm_pilot_exec.py::test_frozen_store_and_policy_files_unchanged`는 보호 경로(`matcher.py` 포함)가 **HEAD 대비 미커밋 변경이 없는지**만 봅니다.
- 이 변경을 커밋하기 전에는 실패하고, **커밋하면 검사 내용과 무관하게 통과**합니다. 검사 자체는 승인 여부를 확인하지 않습니다.
- 따라서 이 변경의 승인은 이 기록과 커밋 승인으로 남겨야 합니다.
- 유료 실행 승인 기록에는 `docs/llm_pilot_final_plan.md` 7절에 따라 실행할 커밋 해시를 새로 적어야 합니다.

승인된 정책 결정 (2026-10-24)
1. 기준선은 64d471b로 기록합니다.
2. 기존 테스트 기대값 3건(E9 영어 기록, 상위 개념 → TFCC, 폐경 → 임신·수유)의 변경을 승인합니다.
3. 기준의 IV contrast와 요오드 조영제의 동등성을 코드가 임의로 확정하지 않습니다.
4. 폐경 이력만으로 임신·수유 복합 기준을 자동 확정하지 않습니다.
5. 현재 `qa_log`는 Session에서 Matcher로 연결하지 않습니다. 연결 전 필요한 보완: 같은 질문의 수정 답변, 같은 기준에 연결된 답변 간 상충, 환자·세션 식별자 연결.
6. 기존 파일럿 결과(`matcher-baseline`)와 수정 후 결과(`evidence-directness-v1`)는 별도 정책 버전으로 구분합니다.

## 5. 지원하지 않는 범위 (검사하지 않음 -> LLM 판정을 그대로 둠)

- 개념군(알레르기·금기, 임신·수유) 밖 기준의 개념어·대상 일치: 바이오마커, 병기, 진단 세부형, 감염, 동반 질환 대부분
- 특정 시술·치료 이름이 약어가 아닌 일반 낱말일 때(예: "ligament reconstruction")와 한국어 번역명(TURBT ↔ 경요도 방광종양 절제술). 약어 규칙은 '있음' 판정에만 적용
- 부재(no) 판정의 기간 조건(예: "4주 이내 수술 없음"을 2020년 수술 기록으로 판정)
- 기준 안의 '또는' 구조: E9의 "조영제 금기 또는 CTU/MRU 촬영 불가" 중 두 번째 갈래는 따로 확인하지 않음
- 기준에 부정어나 결과값('negative', '음성', "No known allergy ..." 등)이 있으면 근거 극성과 판정의 대응을 검사하지 않음. 판정을 보류하지 않고 건너뜀
- 부정형 기준("No rituximab ... within 6 months")에서는 holds=yes를 '없음' 주장으로 보고 기간·대상·결과 검사를 '있음' 주장에만 적용. 부정형 판별은 문장 앞의 No/Without, "no prior/known/history", 한국어 "~없음/~않은" 끝맺음만 봄
- 대상을 밝히지 않은 기록상 부재("No known allergies")를 모든 대상의 부재로 볼지는 임상 판단. 현재는 그렇게 봄
- 한국어 활용형·표현 목록에 없는 추측 표현(예: "~했나 봐요")
- 개념군 밖의 상충은 같은 대상어가 두 절에 모두 있을 때만 잡음
- 현재 `Session.match`는 `qa_log`를 넘기지 않으므로, 실제 흐름에서 짧은 객관식 답변만으로는 확정하지 않음(기존과 같음). 연결하려면 보호 파일 `pipeline.py`에 한 줄 변경과 별도 승인이 필요
